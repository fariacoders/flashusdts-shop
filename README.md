# FLASH USDTS SHOP

This is a marketplace for high-quality code snippets, automation scripts, and educational materials from expert developers worldwide.

## Getting Started

First, run the development server:

```bash
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

## Available Scripts

In the project directory, you can run:

- `bun dev`: Runs the app in the development mode.
- `bun build`: Builds the app for production to the `.next` folder.
- `bun start`: Starts the application in production mode.
- `bun lint`: Runs ESLint to find and fix problems in your code.
- `bun test`: Runs Playwright to perform end-to-end tests.
- `bun format`: Formats the code using Prettier.
